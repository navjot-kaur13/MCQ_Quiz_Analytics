# MCQ Quiz Analytics

**Purpose:** Analyze MCQ quiz responses, generate overall statistics, individual stats, and visualizations.

## Files
- `src/` : Source code files
- `data/` : Sample MCQ responses (CSV/JSON)
- `graphs/` : Saved plots or generated charts
- `README.md` : Project explanation

## How to Run
1. Make sure Python is installed.
2. Navigate to `src/` folder.
3. Run the main code file (e.g., `main.py`).
4. Generated graphs will be saved in the `graphs/` folder.

## Features
- Overall quiz statistics: total questions, attempted, correct/incorrect.
- Individual user statistics.
- Visualizations: bar charts, pie charts, trend charts for performance.
